# GD Impossible Levels List

This repository contains a simple static web app for managing an impossible Geometry Dash levels list.

Features included:
- Public approved list of levels
- Submissions from logged-in users
- Admin review queue for pending submissions
- Approve, decline, or move a submission back to pending
- Account creation and login
- Thumbnail URL support for PNG, GIF, JPG, or WebP images
- YouTube video ID entry and embed
- Bold Arial styling throughout

Getting started:
1. Open `index.html` in a browser.
2. Log in as the default admin account:
   - Username: `admin`
   - Password: `admin123`
3. Use the admin panel to approve or decline submissions.
4. Create additional accounts from the Create account tab if needed.

Notes:
- This is a client-side app using localStorage, so data is stored in the browser on the device running it.
- It is meant as a lightweight prototype for a static site.
- If you want a production version with real authentication and database storage, you would need a backend (for example Node.js/Express, Next.js, Firebase, Supabase, or another service).
